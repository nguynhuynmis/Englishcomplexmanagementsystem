📋 CHỌN CÁCH DEPLOY CỦA BẠN:

[ ] Option A: Subfolder        (yoursite.com/english-complex)
[ ] Option B: Subdomain        (english.yoursite.com)  ← KHUYẾN NGHỊ
[ ] Option C: Root domain      (yoursite.com)

========================================

🔧 CẤU HÌNH (chọn 1 trong 3):

┌─────────────────────────────────────┐
│ OPTION A: SUBFOLDER                 │
└─────────────────────────────────────┘

1. Sửa file: vite.config.ts
   base: '/english-complex/',

2. Rebuild:
   npm run build

3. Upload build/* vào:
   /public_html/english-complex/

4. Tạo .htaccess trong /public_html/english-complex/:
   
   <IfModule mod_rewrite.c>
     RewriteEngine On
     RewriteBase /english-complex/
     RewriteCond %{REQUEST_FILENAME} !-f
     RewriteCond %{REQUEST_FILENAME} !-d
     RewriteRule ^ /english-complex/index.html [L]
   </IfModule>

5. Truy cập:
   yoursite.com/english-complex

┌─────────────────────────────────────┐
│ OPTION B: SUBDOMAIN (KHUYẾN NGHỊ)  │
└─────────────────────────────────────┘

1. Tạo subdomain trong Hostinger:
   - Name: english
   - Document Root: /public_html/english

2. Sửa file: vite.config.ts
   base: '/',

3. Rebuild:
   npm run build

4. Upload build/* vào:
   /public_html/english/

5. Tạo .htaccess trong /public_html/english/:
   
   <IfModule mod_rewrite.c>
     RewriteEngine On
     RewriteBase /
     RewriteCond %{REQUEST_FILENAME} !-f
     RewriteCond %{REQUEST_FILENAME} !-d
     RewriteRule ^ /index.html [L]
   </IfModule>

6. Truy cập:
   english.yoursite.com

┌─────────────────────────────────────┐
│ OPTION C: ROOT DOMAIN               │
└─────────────────────────────────────┘

⚠️  LƯU Ý: Sẽ ghi đè WordPress nếu có!

   (Cẩn thận nếu đã có WordPress!)

5. Truy cập:
